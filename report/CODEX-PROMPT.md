## 1. 什么情况适用什么版式（场景 → 格数 N → 版式决策表）

先算节拍：`N = 台词回合数 + 动作拍数 + 1 个落点`（1 个气泡组 1–3 句 = 1 拍；1 次挥/挡/落/眼神停顿 = 1 拍；落点 = 本页最后要读者记住的那一格）。

| 剧情场景 | 推荐格数 N | 倾斜分格 (L13) | 适用版式（按优先级排序） | 选版式铁律 |
|---|---|---|---|---|
| **日常对话** | **4–6 格**（首选 5 格） | 禁用 | **L14（`1-2-2` / `2-1-2`）**、**L8（`1-2-1`）**、**L9（`2-2-2`）**、**L15（`1-1-2`）** | 两人来回对话首选 5 格 `1-2-2` 或 `2-1-2`（比 `1-2-1` 多一拍微表情格）；三人以上用 `2-2-2` |
| **情报解释 / 设定说明** | **4–6 格**（首选 5 格） | 少用 | **L15（`1-1-2` / `2-1-1`）**、**L8（`1-2-1`）**、**L17（`1-2-1-1`）**、**L16（`1-2-3`）** | 说话人给中景（T4），中间必须穿插 **T7（眼/手局部）**、**T8（物件）** 与 **T14（黑底总结条）** 打破沉闷 |
| **对峙 / 放话** | **3–5 格** | 可微斜 | **L14（`1-2-2`）**、**L8（`1-2-1`）**、**L4（`1-2` 上大下双）**、**L6（`1-1-1`）**、**L18（`1-3`）** | 强压迫感用 **L4**（上大格给全身/背影，下双格给眼神交锋）；慢节奏逼近用 **L6**（三段横条递进特写） |
| **战斗交锋（挥砍/追击）** | **3–5 格**（首选 4 格） | **必用（88% 页倾斜 4–10°）** | **L13 斜切 + L4（`1-2`）** / **L3（`1-1`）** / **L6（`1-1-1`）** / **L18（`1-3`）** / **L14（`1-2-2`）** | 主动作占上带或通栏大格（T10），配合 2–3 个窄格或竖格切刀锋、残影、单眼（T7） |
| **受击 / 爆发 / 失衡** | **2–4 格** | **必用（81% 页倾斜）** | **L13 斜切 + L4（`1-2` 上大冲击）**、**L3（`1-1` 两段对撞）**、**L10（竖分栏通高斩击）** | 格数必须少（2–4 格），留出 35–55% 页面面积给 **T11（墨块/白闪/爆炸线）** 或 **T10（受击飞出）** |
| **揭晓 / 反转** | **1–4 格**（首选 3–4 格） | 可用 | **L5（`2-1` 上双下大）**、**L15（`2-1-1` 底大格）**、**L1（满版/跨页）**、**L4（`1-2`）** | 先用 2–3 个小格铺垫或给惊愕反应，**在页尾或翻页满版给 ≥40% 的 T6（面部大特写）或 T2（登场全身）** |
| **情绪顶点 / 心理重击** | **3–5 格** | 可用 | **L7（`1-1-1-1` 四段横条）**、**L17（`1-2-1-1`）**、**L18（`1-3-1`）** | 靠密集的 **T6（面部特写）+ T7（瞳孔/嘴角/手颤抖）+ T14（黑底白字）** 连续推进，背景留白或涂黑 |
| **转场 / 换地点** | **2–5 格** | 禁用 | **L8（`1-2-1`）**、**L7（`1-1-1-1`）**、**L10（竖分栏）**、**L3（`1-1`）** | 页首第 1 格必放 **T1（建筑/街道建立）** 或 **T9（天空/走廊空镜）**，或用一条 **T14 黑底带** 切开时空 |
| **章首（开场与标题）** | **1–4 格** | 视动作而定 | **L2（`1-1-1` / `2-1-1` + 底部 5% 标题带）**、**L1（独立标题扉页）** | 第 1 页用 3–4 格快速切入钩子并在页底印小标题；或先演 4–8 页序幕，在转折处放 **L1 黑底/插画大标题页** |
| **话末（悬念收尾）** | **1–3 格** | 少用 | **L1（满版）**、**L5（`2-1` 上双下大）**、**L3（`1-1` 上下两段）** | 格数全话最少（1–3 格）。最后一格必是 **T6（决意/惊愕大脸）**、**T12（压迫背影/剪影）** 或 **T14（黑底悬念台词）** |

## 3. 十八种标准版式与「每格内容标签」精确对应表（L1–L18）

> 读法：`[1-2-2]` 表示上带 1 整格、中带左右 2 格、下带左右 2 格。`P1…PN` 按阅读顺序编号。

### A. 1–3 格冲击与基础族
- **L1 满版 / 跨页半幅**｜`[1]`（单格占 85–100%）
  - **何时用**：话末悬念、角色登场、必杀命中、连载标题页（一话不超过 2 页）
  - **各格标签**：`P1(整页)` = **T2 远景全身** / **T10 动作大招** / **T6 面部特写** / **T12 剪影** / **T15 标题海报**（留白或纯黑 ≥30%）
- **L3 上下两段 / 对半双格**｜`[1-1]`（上下各半）或 `[2]`（左右通高对半）
  - **何时用**：一击必杀（起手→命中）、转场（空镜→人物）、情绪重击（特写→黑底）、两人并立对峙（左右通高）
  - **各格标签**：`P1(上, 45–55%)` = **T10 动作** / **T1 建立** / **T9 空镜** / **T2 全身** → `P2(下, 45–55%)` = **T6 面部特写** / **T11 冲击效果** / **T7 眼部局部** / **T13 惊愕反应**
- **L4 上大下双**｜`[1-2]`（上带 52–68% 整格，下带左右 2 格）
  - **何时用**：受击爆发、揭晓、对峙——先给占半页的动作或双人场面，底下两格给双方反应
  - **各格标签**：`P1(上大格)` = **T10 动作** / **T3 双人对峙** / **T11 冲击爆炸** → `P2(下先读格)` = **T7 眼/手局部** / **T4 说话** → `P3(下后读格)` = **T6 面部特写** / **T13 惊讶反应**
- **L5 上双下大**｜`[2-1]`（上带左右 2 格，下带 52–68% 整格）
  - **何时用**：反转揭晓、话末顿点——上面两小格问答或动作铺垫，底部大格抛出重磅落点
  - **各格标签**：`P1(上先读格)` = **T4 说话** / **T7 局部** → `P2(上后读格)` = **T5 听者反应** / **T13 惊讶** → `P3(下大格)` = **T6 面部大特写** / **T10 大动作** / **T2 全身登场** / **T14 黑底台词**
- **L6 三段横条**｜`[1-1-1]`（33% / 26% / 33% 三条全宽横带）
  - **何时用**：战斗三连拍、慢推镜、三拍均匀递进
  - **各格标签**：`P1(上带)` = **T8 物件** / **T10 动作** / **T3 双人** → `P2(中带)` = **T6 特写** / **T4 说话** / **T7 眼部横条** → `P3(下带)` = **T6 特写** / **T7 局部** / **T9 空镜**
- **L12 黑底 / 界面格**｜纯黑底或 UI 框（可独立成页，更常作为单格嵌入多格页）
  - **何时用**：电话画外音、内心独白、游戏 UI 读条、能力名宣告、话末卡
  - **各格标签**：`黑底格` = **T14 台词/旁白格**（纯黑底白字，居中或竖排）；`界面格` = **T15 界面/符号**

### B. 4 格主力叙事族
- **L15 不对称三段四格（4 格第一高频）**｜`[1-1-2]` 或 `[2-1-1]`
  - **何时用**：情报解释、战斗衔接、带底部特写落点的对峙问答
  - **`[1-1-2]` 各格标签**：`P1(上宽)` = **T3 双人** / **T4 说话** / **T9 空镜** → `P2(中宽)` = **T6 特写** / **T3 双人** / **T1 建立** → `P3(下先读)` = **T7 眼/手局部** → `P4(下后读)` = **T5 听者** / **T3 双人**
  - **`[2-1-1]` 各格标签**：`P1–P2(上双格)` = **T4 说话 + T5/T6 听者** → `P3(中宽)` = **T7 局部** / **T6 特写** → `P4(底大格)` = **T6 面部大特写** / **T3 双人**
- **L8 三明治 `1-2-1`**｜`[1-2-1]`（上 32% 整格 / 中 28% 左右两格 / 下 34% 整格）
  - **何时用**：标准 4 句对话页、攻防一回合（建立 → 交锋 → 收束）
  - **各格标签**：`P1(上宽)` = **T1 建立** / **T3 双人** → `P2(中先读)` = **T4 说话** / **T6 特写** → `P3(中后读)` = **T5 听者** / **T4 反打** → `P4(下宽)` = **T7 眼/手局部** / **T6 特写** / **T9 空镜**
- **L18 三竖列复合 `1-3` / `3-1`**｜`[1-3]`（上大格 45–55% + 下带并排 3 个竖窄格）
  - **何时用**：大场面后紧跟高速动作三连拍（跳下/逼近/挥刀），或三人同时反应（常配合 L13 斜切）
  - **各格标签**：`P1(上大格)` = **T1 建立** / **T10 动作** / **T3 双人** / **T11 冲击** → `P2–P4(下并排三竖格)` = 动作连拍用 **T10 → T10 → T13**；多人反应/逼视用 **T7(眼) → T6(A 脸) → T6/T13(B 脸)**
- **L7 四段横条**｜`[1-1-1-1]`（四条全宽横带）
  - **何时用**：心理压迫、慢镜头逼近、一问一答回合制
  - **各格标签**：`P1(顶带)` = **T4 说话** / **T6 特写** / **T3 双人** → `P2(二带)` = **T6 特写** / **T7 眼部** → `P3(三带)` = **T6 特写** / **T8 物件** → `P4(底带)` = **T7 局部** / **T14 黑底文字条** / **T9 空镜**
- **L2 章首标题带页**｜3–5 格骨架 + 底部/格间 5% 白底标题带
  - **何时用**：每话第一页正片，或话中转场标题页
  - **各格标签**：`P1` = **T1/T2 建立** 或 **T12 剪影** → `P2–P3` = **T3/T4 出场** + **T7/T13 钩子** → `底格` = **T6 特写 / T10 动作** + `标题带(章号+英/中题)`

### C. 5 格黄金叙事族（全书占比最高，主力版式）
- **L14 三段五格 `1-2-2` / `2-1-2` / `2-2-1`**｜两条双格带 + 一条整宽大格
  - **何时用**：**全书使用率第一的对话与攻防版式**（1 个定调大格 + 2 组双格完成两回合交锋与局部反应）
  - **`[1-2-2]`（上大 + 中双 + 下双）各格标签**：
    - `P1(上大格 30–40%)` = **T1 建立** / **T3 双人** / **T6 特写**
    - `P2–P3(中双格)` = **T4 说话** + **T5/T3/T7 听者或反打**
    - `P4–P5(下双格)` = `P4` **T6 面部特写** + `P5` **T7 眼/手局部**（或 **T6 特写**）
  - **`[2-1-2]`（上双 + 中大 + 下双）各格标签**：
    - `P1–P2(上双格)` = **T6/T7 局部或表情** + **T4 说话 / T10 动作**
    - `P3(中大格 30–40%)` = **T3 中景双人同框主格** / **T10 主动作**
    - `P4–P5(下双格)` = **T7 眼/手局部** + **T6 面部特写收束**
  - **`[2-2-1]`（上双 + 中双 + 下大）各格标签**：
    - `P1–P4(上中四小格)` = **T4/T10** 与 **T7/T5** 连续快切铺垫
    - `P5(下大格 35–45%)` = **T10 爆发动作** / **T6 面部大特写**
- **L17 五格条带/三竖复合 `1-1-3` / `1-3-1` / `1-2-1-1` / `2-1-1-1`**
  - **何时用**：在三段式里切一层三竖格，或在四格页顶/底插入一条 L11 窄条带（眼部或黑底旁白）
  - **`[1-1-3]` 各格标签**：`P1(上宽)` = **T6/T7** → `P2(中宽)` = **T3/T4** → `P3–P5(底三竖格)` = **T7 局部 → T6 特写 → T4 说话**
  - **`[1-2-1-1]` 各格标签**：`P1–P4` 同 **L8 三明治** + `P5(底窄条 8–15%)` = **T7 眼部局部** / **T14 黑底单句** / **T8 物件**

### D. 6 格以上高密度与特殊几何族
- **L9 对称六格 `2-2-2`**｜`[2-2-2]`（三层双列）
  - **何时用**：三人以上轮流发言、快节奏问答
  - **各格标签**：`P1–P2(上带)` = **T3 双人 + T4 说话** → `P3–P4(中带)` = **T6 特写 + T4 说话 / T7 局部** → `P5–P6(下带)` = **T7 局部 + T6 特写收束**
- **L16 不对称六格/多格 `1-2-3` / `2-1-3` / 群像竖列**｜含 3–4 个并列竖窄格的多层版式
  - **何时用**：队长群像登场、多人同时震惊、高速连击拆解、闪回蒙太奇（比 `2-2-2` 常见 4 倍）
  - **各格标签**：`宽格槽(1格带)` = **T3 双人 / T1 建立 / T10 主动作**；`双格槽(2格带)` = **T4 说话 + T5/T6 反应**；`三/四竖格槽(3–4格带)` = 并排连续 **T7(眼/手) + T6(多张特写脸) + T4(短句)**
- **L10 竖分栏（T 型通高长栏）**｜一侧通高长栏（高 65–95%、宽 38–50%），另一侧叠 2–3 个小格
  - **何时用**：全身站姿亮相、竖排能力名宣告、纵向斩击、走廊/门口竖空间、贴脸半面特写
  - **各格标签**：`通高长栏(左或右)` = **T2 远景全身** / **T6 纵向半脸大特写** / **T12 背影** / **T10 纵向斩击**；`短栏 1–3(上→下)` = **T7(眼/脚) → T4/T5(说话/反应) → T6(脸部收束)**

  - **各格标签**：`条带槽` = **T7 眼部/手指局部（首选）** / **T14 黑底单句台词** / **T8 物件** / **T9 窄空镜**（一页最多 2 条，绝不放两张脸）

  - **何时用**：战斗（88% 用）、受击爆发（81% 用）、失衡冲击
  - **各格标签**：`斜切大格` = **T10 动作** / **T11 冲击线**（斜线方向必须 = 刀路/视线/受力方向）；`斜切楔形小格` = **T7 睁大的单眼** / **T13 咬牙冒汗** / **T6 怒吼特写**（纯对话页禁用倾斜，T14 文字格永远水平）

## 5. 四条构图铁律

1. **大格定位**：一页最多一个 ≥25% 的主导大格（满版除外），与邻格面积比 **2:1–3:1**。
   - **战斗起手 / 场景切入 / 压迫对峙**：大格放**页首（上带）**；
   - **反转揭晓 / 情绪重击 / 话末悬念**：大格放**页尾（下带）**；
   - **双人交锋主格（`2-1-2`）**：大格放**中带**。
2. **景别与局部穿插**：整体按「远 → 中 → 近 → 特」推进，但在中景/近景对话之间，**每页必须穿插 1 格 `T7`（眼/手/嘴局部）或 `T8`（物件）** 来控制呼吸节奏。
3. **视线面对面**：同排左右并列的两格，人物必须**视线相对（面对面）**，严禁同排两人朝同一方向各说各话；背对时必须给越肩或剪影（`T12`）。
4. **气泡与留白**：气泡占格面积 20–35%，绝不压眼睛；一格最多 3 个气泡（超过即拆格）；无框出血格一页最多 1–2 处。

## 6. 禁忌

全页格等大｜连续 3 格同一景别且无 T7 局部格打断｜左右并排人物同向｜连续 2 格以上无框｜全页每格都画整张脸（缺环境与局部）｜一格塞 4 个以上气泡｜条带里放两张脸｜纯对话页用倾斜分格｜同页斜边角度不平行｜编造 `character-panels-index.json` 中不存在的文件名。
