## 判定标准

「纯场景」＝画面主体是**环境、建筑、室内、街道、天空、自然景观**，并且**没有人物或生物主体**。

排除的情况：出现任何人物（哪怕只有一角脸、头发、手、背影、剪影、被裁切的身体局部、远处的小人影）；怪物／虚的形态；纯白、纯黑、空白或只有网点底色；标题美术字、Logo、目录页、角色介绍框；纯文字格；只有速度线／效果线；裁切到看不出内容、或只剩一条边的碎片。

几条细则：远景飞鸟、云中鸟影按自然景观处理，不算人物；钟表、易拉罐、拉面碗这类道具特写、招牌文字特写不计入场景；带站点水印且水印压住主体的图已剔除。

## 命名规则

- 分格：`cXXX_pYYY_gNN.jpg` ＝ 章节号 `cXXX`、页码 `pYYY`、该页第 `NN` 个分格（分格按从上到下、从左到右编号）
- 整页：`cXXX_pYYY.jpg`
- 例：`c430_p005_g01.jpg` = 430 话第 5 页第 1 格

`index.csv` 里的「分格ID」与「来源页」可直接回溯到 `by-source/` 下的原扫描页。

## 做法

1. **切分格**：两套算法互补——(a) 按长白游程找格间白槽递归切分；(b) 按黑色边框围出的闭合区域取格。两套结果合并去重，得到 4869 个分格。
2. **全量审核**：4869 个分格做成 134 张 8×5 拼版图逐格判断，得到 219 个候选（含 unsure）。
3. **放大复核**：219 个候选按 12 格／张放大成 19 张复核图逐张过目，剔除碎片、纯文字格、带人物或道具特写的图。
4. **原尺寸终检**：留下的 92 张再按原始像素逐张看一遍，又剔除了 28 张——包括缩略图上看不见的极小人物／人影、被水印压住的、只剩一条边的、以及文字盖掉大半画面的。

## 已知限制

- **切分不可能全对**：约 220 页（无边框的动作页、速度线跨格的页面）被整页当成一格，这类页面里如果藏着场景可能被漏掉；反过来，个别画面被多切开的碎片已在复核时剔除。
- 分格原样保留黑色边框线，没有做去框、去网点的清理。
- B 级的文字无法从画面中去除，需要干净底图时请自行裁切或修图。
- `index.csv` 的「重复组」标出近似重复（同一场景在不同页重复使用，如 D1、D2…），可按需只留一张。
