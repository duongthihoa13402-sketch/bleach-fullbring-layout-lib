# 融合参考小样（20 张）

这一套不是"纯场景"，而是**人物和环境同框**的镜头：人物站在可读的环境里，能看出他/她是怎么"落"进那个空间的。用来先确认取图方向对不对，再决定要不要铺全量。

## 先看这三组

1. **`00-配对对照_02与18.jpg`** — 同一个店门口，左边有人、右边没人。这是最有价值的一种参考：同一场景"加人前 / 加人后"，能直接看出脚印位置、影子方向、人物与门板的比例关系。
2. **`19-细节-接地与投影`、`20-细节-门框与人物`** — 把画面放大到只看脚和地面、只看人物边缘与门框。融合真正出问题的地方就在这几厘米：接地有没有对齐、影子方向对不对、人物边缘的白有没有和背景分不开。
3. **`03`、`04`** — 人物小到只占几个百分点也算融合参考：它们告诉你"人物该多大、地平线该多高"。

## 20 张的构成

| 类别 | 数量 | 看什么 |
| --- | --- | --- |
| 远景 | 4 | 地平线高度决定人物大小；靠建筑/街道的透视线把空间立起来 |
| 中景 | 9 | 人物全身或大半身 + 可辨识环境：门框遮挡、栅格压身、窗光逆光、投影落地 |
| 全景/夜景 | 4 | 人物在整间屋/大厅/夜色里，看空间分层与明度对比 |
| 配对空镜 | 0 张人物 | 与 `02` 同场景的空镜，对照用 |
| 局部放大 | 2 | 接地、投影、门框留白这些融合细节 |

## 标注

`sample-index.csv` 每张都标了：类别、场所、时段/光、融合手法、人物占比（目测）、说明。扩到全量时就按这几列打标签——**标注比张数重要**。

## 和已有 64 张纯场景的关系

- 64 张纯场景 = **底**（L1）：知道场景长什么样，但没有"人怎么放进去"的信息。
- 这套融合帧 = **规则**（L2）：透视、接地、明度分层、遮挡、光源、空气透视，六条规则都在同框画面里。
- 配对 + 局部放大 = **对照**（L3）：直接能学、能比对。

## 扩到全量的规模

按这次小样的命中率估计，全 56 章的"人物＋环境"帧大约能挑出 **150–250 张**，再配 **20–30 组**同场景空镜对照。全量做法不变：先按"每章开场几页 + 大格"取候选，再逐张人工过目并打标签。
