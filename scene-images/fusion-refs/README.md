# 融合参考：人物＋环境（141 张）

这是"人物站在环境里"的参考集，用来研究**人物怎么和环境融合**——透视、接地、投影、明度分层、遮挡、光源。不是纯场景集（纯场景是 `../` 那 64 张，属于"底图"）。

## 目录

| 位置 | 数量 | 内容 |
| --- | --- | --- |
| `远景/` | 28 | 环境主导，人物很小：看地平线高度、人物该多大、透视线怎么收 |
| `中景/` | 104 | 人物半身到全身，背景清晰：门框/墙体分层、栅格压身、窗光、地面投影 |
| `近景/` | 9 | 人物占大半，但背景仍能认出是什么：看人物边缘与背景的明度分离 |
| `contact-sheets/` | 16 张 | `总览_01–06`（全部 141 张）+ 按场所分的 `室内_01–04`、`建筑外_01`、`自然_01–02`、`街道_01`、`夜景_01` |
| `pairs/` | 1 组 | 同场景"空镜 ↔ 有人"对照（浦原商店），见下方说明 |
| `fusion-index.csv` | 141 行 | 文件、分格ID、景别、场所、时段、融合手法、说明、宽高 |

## 标注

- **景别**：远景 / 中景 / 近景
- **场所**：室内 77、自然 25、建筑外 24、街道 11、夜景 3、其他 1
- **时段**：白天 130、夜 11（按画面判断，粗略标注）
- **融合手法**：按场所给的"这一类该看什么"（例如室内＝门框/墙体分层、地脚线做水平基准、人物脚下的投影）。这是类别级提示，不是逐张的技术分析。

## 关于配对

原本想做 20–30 组"同场景空镜 ↔ 有人"的对照。试过按章节+页码邻近自动配对，跑出来的 46 组候选**几乎全是假配对**（同一章不同地点），所以没有硬凑，只保留了 1 组肉眼确认过的：

- `pairs/01-浦原商店_空镜与有人.jpg`——左边有人（`c427_p012_g01`），右边空镜（`c473_p023_g02`），同一个店门口，能直接对照脚印位置、影子方向、人物与门板的比例。

**这个时期同机位重复取景的情况本来就少**，所以改用"按场所分组"来做对照：想比较"人怎么站在房间里"，就看 `contact-sheets/室内_*.jpg`；想比较街道，就看 `街道_01.jpg`。

## 怎么用（两个用途）

- **自己做画/临摹**：先看 `远景` 定比例关系，再看 `中景` 的门框/栅格/窗光怎么切人物，最后放大看脚和地面。`../_fusion-sample/19-细节-接地与投影`、`20-细节-门框与人物` 是现成的局部放大示例。
- **AI 生成/重绘**：拿 `中景` 当构图参考最稳（人物占比 30–50%、背景结构清楚）；要生成"人物在场景里"，比给模型纯背景图更有效。

## 已知限制

- **141 张**：原本预期 150–250。实际筛下来，很多分格是"两格被切成一张"的错误裁切，这类不能当参考，全部剔除了；另外动作戏里"人物站在速度线/网点上"的格子也没有可辨识空间，不算融合帧。所以数量落在 141。
- **室内偏多**（77/141）：完全现术篇本来就是日常+对话为主，街道和自然镜头偏少。
- 分格保留原扫描的边框线和站点水印（个别张），没有做修复。
- 时段（白天/夜）是按画面粗判的，个别黄昏/阴天可能标成白天。
